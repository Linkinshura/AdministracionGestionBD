# Ejercicio 1:

1. Diseñar el modelo entidad-relación de una empresa
Una empresa vende productos a varios clientes. Se necesita conocer los datos personales de
los clientes (nombre, apellidos, dni, dirección y fecha de nacimiento). Cada producto tiene un
nombre y un código, así como un precio unitario. Un cliente puede comprar varios productos a
la empresa, y un mismo producto puede ser comprado por varios clientes. Los productos son
suministrados por diferentes proveedores. Se debe tener en cuenta que un producto sólo
puede ser suministrado por un proveedor, y que un proveedor puede suministrar diferentes
productos. De cada proveedor se desea conocer el NIF, nombre y dirección.

### a) Identificación de Entidades (Tablas)

Clientes(DNI, nombre, apellidos, direccion, fecha_nacimiento)
Productos(ID, nombre, precio)
Proveedores(NIF, nombre, direccion)

| Nombre    | VARCHAR      | 50      | NOT NULL      |                 |     |

| Direccion | VARCHAR      | 80      | NOT NULL      |                 |     |

### c) Identificación las relaciones y su cardinalidad

Clientes 1:M Productos_Comprados

Productos M:1 Proveedores
